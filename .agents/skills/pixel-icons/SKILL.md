# Pixel icons

Every icon in `packages/app` is a 16x16 sprite drawn as a text grid in `src/lib/pixelIcons.ts` and rendered by `src/components/PixelIcon.tsx` (react-native-svg, one path per color). There are no emoji or icon fonts. Do not add a vector icon library.

## Where things live

- `src/lib/pixelIcons.ts`: the sprite table `PIXEL_ICONS`. Generated by the script below, do not hand-edit rows in it.
- `src/components/PixelIcon.tsx`: `<PixelIcon name="Coins" size={ms(20)} />`. Decorative, so put the accessibility label on the Pressable around it.
- `src/components/IconText.tsx`: sprite plus text on one line, `<IconText icon="Calendar" style={...}>Due today</IconText>`.
- `src/lib/iconMapper.ts`: `toPixelIcon(name)` turns a stored vault or tag icon name into a sprite name, with a `CircleHelp` fallback.
- Components take an `icon: PixelIconName` prop (`Button`, `SheetHeader`, `SettingLink`, `IconButton`, ...). Never pass a string glyph.
- `scripts/pixel-icons.js` in this skill folder: check, add, sheet, list.
- `references/examples.js`: four finished sprites (Coins, Heart, Trash, Key) to copy the style from.

## Workflow

1. Run `node .claude/skills/pixel-icons/scripts/pixel-icons.js list` and check the name is not already there. To redraw one, reuse its name; `add` replaces it.
2. Write a batch file in the scratchpad directory, not in the repo: `module.exports = { Name: { palette: {...}, rows: [...] } }`. Use the lucide icon name in PascalCase (`PiggyBank`, `ShoppingCart`) so stored vault and tag icons resolve.
3. `node .claude/skills/pixel-icons/scripts/pixel-icons.js check <batch.js>` validates the batch and writes a PNG at 8x on the app's surface colors. Read the PNG and look at it. Redraw anything that is not recognizable or looks lopsided. Repeat until `valid` and every icon reads.
4. `node .claude/skills/pixel-icons/scripts/pixel-icons.js add <batch.js>` merges into `pixelIcons.ts`, sorts by name and runs Prettier.
5. Use it: `<PixelIcon name="NewName" />` or an `icon="NewName"` prop. Run `npx tsc --noEmit` in `packages/app`; `PixelIconName` is derived from the table, so a typo fails the build.
6. `... pixel-icons.js sheet Name1 Name2 --out <scratchpad>/sheet.png` renders existing sprites if you need to compare a new icon against its neighbours.

For more than about 10 icons, split them across parallel subagents, one batch file each (b1.js, b2.js, ...), then `add` each batch. Give each agent the format below, the art rules, the exact names, and `references/examples.js`, and tell them to loop on `check` and read the PNG. Do not let two agents write the same file.

## Sprite format

- `rows` is exactly 16 strings of exactly 16 characters. `.` is transparent.
- `k` is the dark outline (#0e0e10) and `w` is white. Both are built in, never put them in `palette`.
- Every other character is a one-character key in `palette` with a `#rrggbb` value. The script rejects unknown keys, wrong sizes and bad colors.
- Max 6 distinct keys per sprite including `k` and `w`.

## Art rules

- Low resolution with visible square pixels. Fill most of the grid and leave about 1px margin.
- Limited palette: usually `a`, `b`, `c` as light, mid and dark shades of one hue (light at top left, dark at bottom right), plus at most one accent key for a detail.
- Every shape gets a 1px `k` outline. Flat or lightly dithered shading, no gradients.
- Keep silhouettes bold. Icons are shown at 14 to 24 px on dark surfaces (#141315 to #353437) and on green and dark-red buttons, so the outline carries the shape.
- UI icons (check, close, arrows, chevrons) need strokes at least 2px thick. Use light grey for neutral controls so they show on the red danger button.
- Pick colors that suit the object and vary them across the set, so neighbours in a picker are easy to tell apart.
- Diagonal shapes (phone handset, pen, brush) and busts of two people are the hardest to read at 16px. Check them first and simplify.

## Adding a vault or tag icon

The icon picker lists `AVAILABLE_ICONS` in `src/lib/static.ts`, which mirrors the web list in `packages/ui/src/lib/helpers/static.ts`. Add a sprite and, only if the web list gets the same name, add it to both lists. A name that has a sprite but is not in `AVAILABLE_ICONS` is a UI-only icon and is fine.

## Using icons in screens

- Sizes go through `ms()` from `react-native-size-matters`, like all other pixel values. Common sizes: 14 in chips and rows, 18 to 24 in buttons and headers, 56 to 96 for empty states and faded background art.
- Icon next to text: `IconText`, or an `icon` prop if the component has one. Do not put a `View` inside `Text`.
- Faded or absolutely positioned icons go in a `View` with `pointerEvents="none"` and `opacity`, since `PixelIcon` has no style prop.
- No hex colors in screens. Sprite colors live only in `pixelIcons.ts`.
